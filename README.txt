CAFÉ NUESTRO — V2
=================

Archivos principales:
- index.html
- style.css
- script.js
- assets/ (imágenes optimizadas)

CAMBIOS PRINCIPALES
- Navbar profesional y menú hamburguesa responsive.
- Hero renovado con mejor jerarquía visual y dos CTA.
- Navegación visual de la carta rediseñada.
- Promociones con presentación comercial más clara.
- Carta completa convertida a formato gastronómico limpio.
- Sección Conócenos en composición imagen + texto.
- Nueva sección Visítanos usando únicamente la ubicación disponible: Av. Vitacura.
- Footer completo.
- Mejoras de accesibilidad, foco por teclado y movimiento reducido.
- SEO básico: title, description y theme-color.
- Imágenes pesadas convertidas a WebP para mejorar rendimiento.

IMPORTANTE
- Se eliminó el ícono de login porque el borrador no tenía funcionalidad asociada.
- Se eliminó el botón de WhatsApp con el número 56900000000 para no publicar un contacto ficticio.
- Cuando tengan el teléfono, Instagram, horario y dirección exacta, conviene incorporarlos en la sección Visítanos y el footer.

DESPLIEGUE EN GITHUB PAGES
1. Sustituir index.html y style.css por los de esta V2.
2. Añadir script.js en la raíz del repositorio.
3. Copiar completa la carpeta assets/ en la raíz.
4. Hacer commit y push.
5. GitHub Pages servirá la V2 sin proceso de build.
